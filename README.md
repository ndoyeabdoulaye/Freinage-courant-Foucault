# Freinage-courant-Foucault
Ce projet porte sur l’étude expérimentale du freinage électromagnétique par courants de Foucault. L’objectif est de comprendre les mécanismes physiques responsables de ce phénomène, d’évaluer la conductivité électrique de différents métaux et d’étudier l’influence de la géométrie du conducteur sur l’efficacité du freinage
